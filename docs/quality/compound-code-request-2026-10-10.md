# 组合代码编辑需求修复（2026-10-10）

用户原句：`优化文件中的代码，再加一条返回语句`。旧运行只修正 `hello word`，遗漏返回语句却显示成功。

## 原因与修改

- 返回语句识别遗漏“再加”“加上”“追加”等措辞；现在覆盖这些表达，仍拒绝删除、否定、非零返回值和 void main 的自动补写。
- 旧逻辑将模型编辑操作整体替换成返回语句操作，不能保留组合需求。新执行函数先应用优化操作，再补足 main 内的返回语句。
- 执行工具使用运行器提供的原始用户需求，不依赖模型缩短后的意图。产物保存前检查真实源码中的返回语句，忽略注释、字符串和只在嵌套块出现的返回。
- 未匹配源码的优化操作、丢失 main 或未满足返回要求均返回失败，不保存为成功产物。单独要求增加返回语句仍保留原有其他内容。
- 重试使用同一执行与校验逻辑；工具摘要和验证结果来自实际修改。原始上传文件保持不变。
