# 界面截图说明

本目录存放 README 使用的界面截图，均为本地启动前端与后端后在浏览器中实际拍摄的页面，没有改写页面内容。拍摄使用本地演示账号与示例数据，不含真实业务资料、凭证或个人信息。

当前 README 顶部与「界面预览」一节使用的截图：

| 文件 | 页面 | 说明 |
| --- | --- | --- |
| `home-chat.png` | 对话工作区首页（`/`） | 本地 mock 后端（内存存储 + mock 模型）下拍摄，内置演示账号登录 |
| `tasks.png` | 智能任务页（`/tasks`） | 同上；尚无运行记录时的空态 |
| `skills.png` | 技能中心（`/skills`） | 同上；列表为系统预置的示例技能 |

目录内其余图片（`workspace-live.png`、`conversation-live.png`、`skills-live.png`、`files-live.png`、`dashboard.png`、`architecture.png`、`index.png`、`system.png` 等）为更早版本的前端界面截图，保留作历史参考，外观可能与当前版本不同。

审批页（`/approvals`）本次未收录截图：本地 mock 后端（内存模式）下其队列接口依赖数据库连接池，页面显示加载失败，动态列表为界面自带的示例数据，不代表真实审批数据。
