# 缺陷审计整改记录 — 2026-10-10

本轮围绕缺陷审计的实际安全边界整改，保留 LangGraph、企业连接器、A2A、文档平面、RBAC 和 Vite 代理诊断。没有为替换库而替换框架；本记录不代表审计中的 42 项全部关闭。

## 已完成

- 数据库租户隔离：迁移 035–037 已在本地应用，57 张内容表启用并强制 RLS。连接在事务内设置 `app.tenant_id`，连接池复用不保留上一次租户。无租户上下文默认不能读取内容。运行账号不具备 superuser/BYPASSRLS；身份和租户目录属于单独的元数据边界。
- 审批：读取与操作绑定租户；不存在或其他租户的请求返回 404。决定先原子占用，再恢复工作流，避免并发重复恢复。外部恢复结果不确定时保留占用并返回 503，不允许重放。
- 登录与刷新：刷新令牌绑定原租户，校验当前成员资格；撤销成员资格后不可刷新。重复开发用户初始化不会重新授予已撤销的成员资格，也不会清空原工作区。
- 审计与偏好：审计写入显式恢复租户事务，查询与导出按租户隔离。用户偏好的查询、写入、确认和删除均校验用户归属。匿名安全事件进入专用 `__forgeflow_security__` 命名空间。
- SSRF：连接经过验证的 IP，同时保留原 Host 和 TLS SNI；每次重定向重新验证，跨源移除敏感认证头，限制解压后的响应体大小。
- 文件与执行边界：ZIP 解压前检查路径、符号链接、重复名称及容量；本地路径注册限制在配置允许的根目录；无租户的运行记录不再公开。安全扫描故障默认拒绝处理，内部错误不直接返回敏感细节。
- 限流：使用 limits 的共享后端接口，开发使用内存；生产要求 Redis，后端故障返回不可用而非放行。
- MCP：升级 FastMCP 4.1，修复命名空间挂载及客户端桥接，移除不兼容且不再使用的适配依赖。
- 前端：统一运行查询键及缓存失效；修复流式读取取消和资源释放；复用原生预览对话框，补齐键盘关闭、焦点约束与关闭后焦点恢复。
- 验证入口：`check-full` 包含浏览器回归和 OpenAPI 数组响应契约检查。数据库测试使用独立随机数据库，结束后仅清理该数据库；测试清理不能删除实际开发数据库。
- 启动恢复：按租户独立事务批量恢复历史运行，避免串行扫描大量命名空间拖慢启动。

## 部署与数据注意事项

## 继续筛查：数据库配置、反馈归属与 SAP 会话

本轮对照了 [HTTPX GitHub](https://github.com/encode/httpx)、[Psycopg GitHub](https://github.com/psycopg/psycopg) 及其官方文档，复用已有依赖，未更换框架。

- 启动检查原先仅验证异步数据库角色，且未开启 RLS 时会跳过角色检查。现同时验证同步与异步连接：运行角色必须不是超级用户、不能 BYPASSRLS，内容表必须启用并强制 RLS；任何连接不符合时关闭新建连接池并拒绝启动。真实数据库验证低权限账号被接受、迁移管理员被拒绝。
- 测试入口也改用低权限同步运行连接，管理员连接仅用于迁移和受隔离数据库名约束的全表清理。旧测试的独立 SQL 读写加入真实租户事务，不再用管理员运行连接掩盖问题。故意移除 WHERE 的测试现在要求 RLS 仍然拒绝跨租户读取，并保留本租户可读的阳性对照。
- 真实低权限回归发现反馈归属判断错误：看不到其他租户行不能代表运行无人认领。新增迁移 039，以全局唯一 run_id 加强制 RLS 保存归属；工作区运行创建时通过同事务触发器登记，首次反馈认领也在同一事务内完成。并发两个租户只有一个能认领，其他租户无法写入影子反馈、上下文或结果。迁移锁定相关表防止回填期间插入遗漏；历史归属冲突保守隔离，不猜测、不删除原记录。
- 修复反馈幂等重放返回错误运行编号的问题，路由重放原事件所属运行，而非为新的请求路径重新标注结果。
- SAP CSRF 获取后的会话 Cookie 原先被丢弃。现使用 HTTPX Cookie 管理保留会话，遵守域、路径和 Secure 规则，令牌刷新重试同时使用新 Cookie，禁用连接器仍保留原行为。[SAP 官方 CSRF 指南](https://help.sap.com/docs/SUPPORT_CONTENT/plm/3472705633.html) 要求后续请求携带服务器返回的 Cookie；[HTTPX 客户端文档](https://www.python-httpx.org/advanced/clients/) 提供会话 Cookie 管理。
- 迁移 039 同时给工作树中新增的 038 事件日志表补齐强制 RLS。本地已应用 038/039 并重新授予低权限角色权限，强制 RLS 的 public 表现为 59 张；反馈归属回填冲突数为 0。原历史内容没有删除。
